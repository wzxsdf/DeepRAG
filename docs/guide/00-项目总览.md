## 一、项目简介

**DeepRAG** 是一个**基于意图分层的 Agentic RAG（检索增强生成）智能问答系统**。

它不是单纯的"检索 + 生成"管道，而是一个能**判断问题性质**、在**知识库检索 / 外部工具 / LLM 常识**三条信息路径间自主协调的智能体系统：

- 问知识库内容 → 检索私有文档，生成带引用的可信答案
- 问实时信息（天气等）→ 调用外部工具获取最新数据
- 问通用常识 → 用 LLM 自身知识回答
- 闲聊 / 能力问询 → 直接友好回应，不打扰知识库

同时具备企业级的**知识库全生命周期管理**（创建 / 上传 / 删除 / 改名，跨三存储一致性保证）和**全过程可观测**的监控看板。

## 三、技术栈

### 后端（Python）

| 技术 | 用途 |
|---|---|
| **FastAPI** | Web 框架，提供 REST + SSE 流式接口 |
| **LangGraph 1.x** | Agent 状态机编排（`Command` 声明式路由） |
| **Qdrant** | 向量 + 稀疏（BM25）检索引擎 |
| **MySQL** | 元数据与审计真相源（aiomysql 连接池） |
| **阿里云 OSS** | 原始文件与派生产物存储（oss2） |
| **SiliconFlow** | Embedding（BGE-M3）+ Rerank（bge-reranker-v2-m3）+ LLM 网关（OpenAI 兼容） |
| **PyMuPDF(fitz)** | PDF 解析（按页 blocks 提取） |
| **passlib + python-jose** | bcrypt 密码哈希 + JWT 鉴权 |

### 前端（TypeScript）

| 技术 | 用途 |
|---|---|
| **React 19 + Vite** | UI 框架与构建工具 |
| **TypeScript** | 类型安全 |
| **Tailwind CSS + shadcn-ui** | 原子 CSS + 组件库（自建 `components/ui/`） |
| **TanStack Query** | 服务端状态（查询 / 缓存 / 轮询） |
| **Zustand** | 客户端状态（auth 持久化） |
| **Framer Motion** | 动画（页面切换 / 卡片入场 / 面板折叠） |
| **Recharts** | 监控图表 |
| **lucide-react** | 图标 |

```
DeepRAG/
├── apps/                       # 应用层

│   │   ├── auth.py             # 注册 / 登录 / JWT
│   │   ├── kb.py               # 知识库 CRUD + 生命周期
│   │   ├── documents.py        # 文档上传 / 确认 / 删除 / 预览

│   │   ├── conversations.py    # 会话历史
│   │   └── monitor.py          # 监控指标
│   └── worker/
│       ├── ingestion.py        # 入库编排（状态机）
│       └── ingestion_core.py   # 解析 / 分块 / 向量化 / 落库

│   ├── agents/                 # Agent 层
│   │   ├── graph.py            # LangGraph CRAG 状态机
│   │   ├── tools.py            # 工具层（检索 agent + 外部工具）
│   │   ├── prompts.py          # 所有提示词
│   │   └── llm.py              # LLM 封装（chat / json / stream / tools）
│   ├── retrieval/              # 检索层
│   │   ├── hybrid.py           # 混合检索（dense + BM25 + RRF）

│   │   └── tokenizer.py        # jieba 分词（默认不启用）

│   └── security/auth.py        # JWT 工具
├── web/                        # 前端（独立 Vite 工程）
│   └── src/
│       ├── pages/              # Chat / KnowledgeBase / Monitor / Login / Register
│       ├── api/                # axios client + 各模块 API
│       ├── store/              # zustand authStore
│       └── components/         # layout + ui（shadcn）

├── docs/                       # 文档（本指南 + W1-W3 验证 + superpowers spec/plan）
└── start.sh                    # 一键启动（后端 :8000 + 前端 :5173）
```

## 五、快速启动

### 1. 环境准备

需配置 `.env`（**不纳入版本控制**，含真实凭证）：

```env
# LLM / Embedding（OpenAI 兼容网关）
LITELLM_BASE_URL=https://...
LITELLM_API_KEY=...
LITELLM_MODEL=gpt-4o-mini
EMBEDDING_BASE_URL=https://...        # SiliconFlow
EMBEDDING_API_KEY=...

# MySQL
MYSQL_HOST / MYSQL_PORT / MYSQL_USER / MYSQL_PASSWORD / MYSQL_DATABASE

# Qdrant（host 须带 http:// scheme）
QDRANT_HOST=http://...
QDRANT_API_KEY=...

# 阿里云 OSS
OSS_ACCESS_KEY_ID / OSS_ACCESS_KEY_SECRET / OSS_BUCKET / OSS_ENDPOINT

# JWT
JWT_SECRET=...
```

### 2. 初始化数据库

```bash
python scripts/init_mysql.py     # 建表 + 老表 ALTER 补列
```

### 3. 一键启动

```bash
bash start.sh
# 后端 http://localhost:8000  (health: GET /health)
# 前端 http://localhost:5173
```

首次使用需注册账号（或用测试账号），登录后即可在对话页提问、在知识库页上传 PDF。
