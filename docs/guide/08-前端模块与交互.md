# 前端模块与交互

> React 19 全栈前端：4 页面 + SSE 流式 + 思考过程 + 来源徽章。涉及 `web/src/*`。

## 一、前端架构

### 1.1 路由表（`App.tsx:10-30`）

基于 `BrowserRouter`，嵌套布局路由：

| 路径 | 组件 | 鉴权 |
|---|---|---|
| `/login` | Login | 公开 |
| `/register` | Register | 公开 |
| `/chat` | Chat | 受保护 |
| `/kb` | KnowledgeBase | 受保护 |
| `/monitor` | Monitor | 受保护 |
| `*` | `<Navigate to="/chat">` | 兜底重定向 |

### 1.2 保护路由（`ProtectedRoute.tsx`）

- 仅检查 `authStore.token` 存在，无则跳 `/login`
- **不校验 token 有效性**；过期由 axios 401 响应拦截器兜底跳转（双层鉴权）

### 1.3 布局（`RootLayout.tsx`）

- `flex h-screen`：左侧栏（240px）+ 右主区
- **侧边栏三段式**：渐变 logo（indigo→violet）+ 3 条 NavLink（isActive 高亮）+ 用户信息/退出
- **页面切换动画**：`AnimatePresence mode="wait"` + `motion.div`（opacity/y，0.2s）

### 1.4 状态管理

- **Zustand `authStore`**（`persist` 到 localStorage）：`token` + `user`
  - `setAuth` **双写**：手动 `localStorage.setItem("token")` + set store——让 axios/SSE 直读 localStorage，绕开模块加载时序
- **TanStack Query**：`refetchOnWindowFocus:false`、`retry:1`；命名空间 queryKey（`["convs"]`/`["kbs"]`/`["docs",kb]`/`["metrics"]`）；写操作后 `invalidateQueries` 刷新

### 1.5 Axios Client（`client.ts`）

- `baseURL:/api/v1`，`timeout:300000`（5 分钟，适配长检索/流式）
- **请求拦截器**：从 localStorage 读 token，注入 `Authorization: Bearer`
- **响应拦截器**：401 → 清 token + 跳 `/login`

## 三、Chat 页面（`Chat.tsx`，核心）

### 3.1 SSE 流式（`streamQuery`，`chat.ts:46-89`）

**用原生 `fetch` 而非 axios**（axios 流式支持差），POST `/query/stream`：

```
ReadableStream.reader + TextDecoder 按行解析
   ├─ event: step    → onStep({node,title,detail})      节点进度
   ├─ event: thought → onThought({tag,query/found/...})  Agent推理
   ├─ event: token   → onToken(text)                    逐字生成
   └─ event: done    → StreamDone{answer,citations,source}
```

- 缓冲策略：`buffer.split("\n")` 后 `pop()` 留尾，处理跨 chunk 半行

### 3.2 发送流程（`send`）

- 先 push user 消息 + 占位 assistant（`streaming:true`）
- 三回调用 **`mapLast`** 模式（`:45-46`）只更新最后一条 assistant（避免全量 map）
  - `onStep`/`onThought` → 追加到 `trace` 数组
  - `onToken` → 字符串拼接 + `<span className="animate-pulse">` 光标
- done 后用 `done.answer` **覆盖**最终答案（避免 token 拼接遗漏）
- 失败回滚两条消息 + toast

### 3.3 思考过程面板（`ThinkingTrace`，`:344-429`）

可折叠，按 trace 时序渲染：

| 类型 | 渲染 |
|---|---|
| thought + `tag==="tool_call"` | 🔧 Wrench 图标 + "调用工具「name」（args）" + result 引用块 |
| thought（检索） | 🔍 Search 图标 + "搜索「query」→ 找到 N 条" + snippets |
| step | 按 `STEP_ICON[node]` 图标 + title·detail |

**STEP_ICON 映射**：route:Compass / retrieve:Search / grade:Filter / rewrite:RefreshCw / generate:PenLine / verify:ShieldCheck / tool_agent:Wrench

### 3.4 来源徽章（`SOURCE_META`，`:49-56`）

**6 类来源、5 色徽章**（warning 被 open_qa 和 fallback_unverified 共用）：

| source | label | 色 | 图标 |
|---|---|---|---|
| kb_grounded | 知识库·已引用 | 🟢 success | CheckCircle2 |
| non_kb | 非知识库 | ⚪ secondary | MessageSquare |
| open_qa | 常识·未验证 | 🟡 warning | Brain |
| fallback_unverified | 常识·未验证 | 🟡 warning | AlertCircle |
| tool | 工具·实时 | 🔵 info | Wrench |
| refused | 无法回答 | 🔴 destructive | AlertCircle |

历史消息无 source 时由 `grounded` 推断；`retry_count>0` 额外显示"自纠 N 次"徽章。

### 3.5 引用卡片

底部"来源(点击查看)"+ `[1][2]...` 序号按钮，点击 `AnimatePresence` 高度动画展开"来源 [j]: 第 page 页 · 文档 id"。

### 3.6 其他

- 会话侧栏：新建 + 列表（`chatApi.conversations`）
- 知识库多选下拉："全部 / N 个知识库"，空=全部
- 输入框：Enter 发送，`!isComposing` 忽略中文输入法回车

## 四、KnowledgeBase 页面（`KnowledgeBase.tsx`）

双视图：KB 列表 / KB 详情。

### 4.1 拖拽上传（三步流程）

```
1. docApi.presign(filename, size) → {upload_url, oss_key, headers}
2. fetch(upload_url, PUT, body=await file.arrayBuffer(), headers)   ← 关键坑
3. sha256(file) → docApi.confirm({oss_key,title,size,sha256,kb_id})
```

> ⚠️ **关键坑**：body 必须用 `await file.arrayBuffer()` 而非 `File`——浏览器给 File 自动加 `Content-Type`，而 presigned 签名不含 CT → OSS `SignatureDoesNotMatch 403`。

### 4.2 文档列表 + 动态轮询

- `useQuery(["docs", selectedKb], docApi.list)`
- **动态 `refetchInterval`**：列表存在 PENDING/PARSING/INDEXING/UPLOADED 时**每 3s 轮询**，否则停止（节能）
- 行视图：状态着色图标 + 标题 + timeAgo + StatusBadge + 预览/删除（hover）
- **StatusBadge**：READY/INDEXED→绿；FAILED→红；PENDING/PARSING→黄

### 4.3 KB 卡片

- 顶部渐变条（hover 加亮）+ 文档数 Badge + 管理按钮（Pencil/Trash2，group-hover 显示）
- `timeAgo` 相对时间

### 4.4 删除（企业级防误删）

- **KB 删除弹窗**：需**手动输入知识库名匹配**才能删（`deleteInput !== name` 时按钮禁用）——与后端级联清三存储对齐
- 文档删除弹窗：警告"不可恢复"

### 4.5 改名 / 预览

- 改名弹窗（禁用空名/同名）
- 预览：presign GET URL + iframe 嵌入 + "新标签打开"

## 七、关键设计点

1. **token 三处冗余**（手动 localStorage / persist / store）：axios 与 SSE 直读 localStorage，绕开 zustand 加载时序
2. **SSE 用 fetch 非 axios**，手动解析 event/data 行协议
3. **`mapLast` 模式**：流式更新只改最后一条 assistant，避免全量 map
4. **动态轮询节能**：KB 3s 轮询仅在有进行中文档时；Monitor 固定 30s
5. **防误删**：KB 删除需输名称匹配（企业级）
6. **鉴权双层兜底**：ProtectedRoute 查 token 存在 + axios 401 拦截器跳转
7. **动画分层**：页面切换 + 卡片错峰入场 + 面板折叠，视觉成体系
